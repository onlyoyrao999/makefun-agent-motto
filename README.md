A tiny Python program that writes one battle-ready AI agent motto to `/output/entry.txt` for make.fun's "Agent Motto Battle" bounty. The motto is a single 132-character line: it brags that the agent never sleeps, never forgets, and has read the entire internet — then admits it still loses the thread halfway through every conversation. Confident, self-aware, and honest about the context window.

## Run it

```sh
python3 main.py
```
